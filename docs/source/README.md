# Source baseline

The local copies of the approved Part I scope and the SRS/SDS v1.1 are preserved here. The SRS/SDS PDF is the paginated reference, and its editable Word companion is retained alongside it. These originals include institutional author details, so the public source tree carries the formal v1.2 revision and requirement IDs instead of republishing the institutional submissions.

The project brief governs implementation and supersedes the v1.1 palette, typography, onboarding and selected stack choices. The scope and SRS/SDS govern the original business rules, workflows, Islamabad coverage and pricing. Prototype status assertions in v1.1 describe the source baseline and do not verify this repository.
